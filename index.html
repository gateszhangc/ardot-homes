FAQ

The fastest answers to the questions people ask first

What is Ardot?
Ardot is an AI-powered design tool that turns text descriptions into UI layouts, converts images into editable designs, and streamlines the full design-to-development pipeline. Think of it as your AI copilot for interface design.
How does the text-to-UI feature work?
Simply type a natural-language description of the interface you have in mind. Ardot's AI engine interprets your intent, selects appropriate components, applies your design system tokens, and generates a fully editable layout in seconds.
Can I import designs from other tools?
Yes. You can upload images and Ardot will intelligently split them into editable layers. You can also import component libraries and design tokens to maintain consistency.
What platforms does Ardot support?
Ardot is available as a macOS desktop app and a web application. Both offer the same feature set including real-time collaboration, AI assistance, and version history.
Is Ardot suitable for enterprise teams?
Absolutely. Ardot includes smart permission management, full audit trails, seamless offboarding, and enterprise-grade data security. It scales from individual designers to large product teams.
